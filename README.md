# בית כנסת בית ישראל — מדריך מלא

<div dir="rtl" align="right">

מערכת קטנה ומלאה: אתר סטטי + עמוד ניהול + אחסון JSON בענן.
הגבאי מעדכן הכל דרך טופס נוח, בלי לגעת בקוד.

---

## מבנה הקבצים

```
beit-yisrael/
├── index.html   ← האתר הציבורי
├── admin.html   ← עמוד ניהול לגבאי (טופס עם שדות לעריכה)
├── data.json    ← תוכן ראשוני. אחרי ההגדרה הראשונית, לא צריך אותו יותר.
└── README.md    ← המסמך הזה
```

## הגדרה ראשונית — פעם אחת בלבד

### שלב 1: יצירת חשבון ב־JSONBin

1. גשו ל־[jsonbin.io](https://jsonbin.io) והירשמו חינם.
2. לחצו על **Create Bin**.
3. הדביקו את התוכן של הקובץ **`data.json`** לתוך העורך.
4. לחצו **Save**.
5. **העתיקו את ה־Bin ID** — הוא מופיע ב־URL של העמוד או בלחיצה על ה־ID.
6. פתחו את תפריט הפרופיל ← **API Keys** ← **העתיקו את ה־Master Key**.

### שלב 2: העלאת הקבצים לשרת

העלו את שלושת הקבצים (`index.html`, `admin.html`, `data.json`) לשרת אינטרנט — למשל:
- **Netlify** — גורר ומשחרר תיקיה בדפדפן, מקבל URL. חינם.
- **Cloudflare Pages** — התקנה דרך GitHub, בונה אוטומטית. חינם.
- **GitHub Pages** — אם כבר יש חשבון GitHub. חינם.
- שרת רגיל שלכם — פשוט מעלים דרך FTP.

### שלב 3: חיבור האתר הציבורי ל־JSONBin

פותחים את **`index.html`** בעורך טקסט, מוצאים את השורה:

```js
const DATA_URL = './data.json';
```

ומחליפים ב־URL של ה־Bin:

```js
const DATA_URL = 'https://api.jsonbin.io/v3/b/BIN_ID_HERE/latest';
```

(מחליפים את `BIN_ID_HERE` ב־Bin ID שהעתקתם).

**חשוב**: כדי שהאתר הציבורי יוכל לקרוא את הבין בלי לחשוף את ה־Master Key, הגדירו את ה־Bin כ־**Public** בהגדרות ב־JSONBin (Access ← Public).

### שלב 4: התחברות ראשונה של הגבאי

1. פותחים את `admin.html` בדפדפן (למשל: `https://your-site.com/admin.html`).
2. מזינים את ה־**Bin ID** ואת ה־**Master Key**.
3. לוחצים **התחבר**.
4. המפתחות נשמרים בדפדפן מקומית — לא יצטרך להזין שוב.

## תחזוקה שוטפת — הזרימה של הגבאי

### כל שבוע (עדכון פרשה + זמני שבת):

1. פותח `admin.html`.
2. בסעיף **״תאריך״** — מעדכן את התאריך העברי והלועזי.
3. בסעיף **״שבת הקרובה״** — מעדכן את שם הפרשה, את פסוק הפתיחה, ואת זמני השבת (הדלקת נרות, מנחה, שחרית, מנחה של שבת, ערבית).
4. בסעיף **״תורת השבוע״** — כותב את דבר התורה של השבוע. אופציונלי: מעביר את דבר התורה הקודם לארכיון (הוספה בסעיף ״ארכיון״).
5. לוחץ **״שמור שינויים״** בתחתית.
6. תאריך העדכון האחרון מתעדכן אוטומטית.

זהו. האתר הציבורי מציג את התוכן החדש מהרגע הזה.

### כל חודש (עדכון זמני חול):

1. פותח `admin.html`.
2. בסעיף **״ימי חול״** — מעדכן את הטבלה של מנחה/מעריב + זמני שחרית.
3. שומר.

### הודעת חירום / באנר צהוב:

בסעיף **״באנר הודעה״** — כותב טקסט (למשל ״מנחה בערב ראש השנה: 18:20״).
הבאנר יופיע ברקע אדום בראש הדף עד שהשדה יתרוקן.

### שיעורים / גבאים / דברי תורה בארכיון:

בכל אחד מהסעיפים יש כפתור **״+ הוסף״** להוספת פריטים, וכפתורי **״מחק״** ו־**↑ ↓** לסידור מחדש.

## שאלות נפוצות

### מישהו חשוד יכול לנחש את ה־Master Key וליצור בלגן?

ה־Master Key נראה כמו `$2b$10$ABC...` — 60 תווים אקראיים. סטטיסטית בלתי אפשרי לנחש.
אבל **מי שהמפתח שלו** יכול לעדכן את הבין ולהחליף את התוכן. לכן: לא לשתף אותו במיילים, לא לשמור אותו במקומות חשופים.

### הגבאי שכח את המפתח מה עושים?

נכנסים לחשבון ב־JSONBin, יוצרים API Key חדש, מוחקים את הישן.
בעמוד הניהול לוחצים **״התנתק״** ומכניסים את המפתח החדש.

### רוצים שלושה גבאים יוכלו לעדכן — כל אחד מהמחשב שלו.

כל אחד מהם צריך את ה־Bin ID ואת המפתח שלו. אפשר ליצור מספר API Keys שונים ב־JSONBin (בהגדרות של החשבון).

### מישהו ערך במקביל ודרס את השינויים שלי?

JSONBin עובד ב־last-write-wins. אם שני גבאים ערכו בו־זמנית, האחרון שלחץ ״שמור״ — מנצח. בשביל בית כנסת שבו מעדכנים פעם בשבוע — לא בעיה. אם זה הופך לבעיה, אפשר לעבור לשירות שתומך ב־optimistic locking.

### אני רוצה לגבות את התוכן

בכל שמירה, JSONBin שומר גירסה חדשה. בעמוד ה־Bin באתר של JSONBin יש טאב **Versions** — אפשר לחזור לכל גירסה קודמת.
כפול־בטוח: להוריד את `data.json` מ־JSONBin פעם בחודש ולשמור בגוגל דרייב.

### אני רוצה לחזור לעריכת JSON ישירות בלי הטופס

בחשבון JSONBin, לוחצים על ה־Bin ומקבלים עורך JSON מובנה עם הדגשת תחביר.
זו האופציה למתקדמים או לתקלות שהטופס לא כיסה.

## שדרוגים אפשריים בעתיד

- **חיבור ל־Hebcal API** — חישוב אוטומטי של הדלקת נרות והבדלה לפי מיקום. הפרשה, זמני שקיעה, ראשי חודשים — הכל אוטומטי בלי עדכון ידני.
- **התראות ווטסאפ** — אחרי שמירה, שליחת סיכום השבת הקרובה לקבוצת הקהילה.
- **דו־לשוני** — הוספת אנגלית לצד עברית.
- **תמונות** — הוספת תמיכה בתמונת ליווי לדברי תורה.

## תמיכה טכנית

הקוד ב־`index.html` ו־`admin.html` הוא HTML+CSS+JS רגיל, ללא ספריות חיצוניות (רק Google Fonts).
אין תלויות. אפשר לפתוח בכל דפדפן, לערוך בכל עורך טקסט, ולהעלות לכל שרת סטטי.
