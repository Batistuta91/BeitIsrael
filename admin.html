הגדרה ראשונית — פעם אחת בלבד

  1. גשו ל־jsonbin.io והירשמו חינם.
  2. לחצו על Create Bin, הדביקו את תוכן הקובץ data.json, ושמרו.
  3. בעמוד ה־Bin שנוצר, העתיקו את ה־Bin ID (מופיע ב־URL).
  4. בתפריט הפרופיל > API Keys, העתיקו את ה־Master Key.
  5. הדביקו אותם למטה ולחצו "התחבר".
המפתחות נשמרים בדפדפן שלכם בלבד, לא נשלחים לשום מקום חוץ מ־JSONBin.
